# AI Agent for Generating Blog Posts

n8n-воркфлоу для массовой генерации SEO-статей с помощью GPT-4o для crowd-marketing и linkbuilding кампаний.

## Что делает
1. Формирует очередь из N задач на генерацию (в примере — 312 шт.).
2. Для каждой задачи запрашивает GPT-4o: агент сам выбирает актуальную для 2025–2026 годов тему в заданной нише, пишет статью 800–1500 слов с SEO-структурой (интро, 2–3 смысловых блока, заключение) и органично вставляет ровно одно упоминание клиентского бренда (`{client_brand}`).
3. Готовый текст сохраняется как отдельный файл в Google Drive с меткой времени в названии.

## Стек
n8n · OpenAI GPT-4o · Google Drive API

## Зачем это нужно бизнесу
Заменяет ручное написание десятков уникальных статей копирайтером на автоматический пайплайн — прямое сокращение времени подготовки контента для размещений (см. кейс: -92% времени на подготовку текстов).

## Настройка
Требуется собственный OpenAI API-ключ (credential в n8n) и доступ к Google Drive (OAuth2). Ключи хранятся в n8n credentials, не в самом workflow-файле.
